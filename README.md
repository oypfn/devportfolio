# Developer Portfolio

A responsive portfolio site to present selected software projects, technical interests and contact information.

## Personalization required before publishing
Replace the placeholder contact email in `src/App.tsx` with a verified address. Review the biography, skill list and availability statement so every claim reflects your real experience. Project descriptions are marked as in development and should only be changed when the linked repositories support those claims.

## Run locally
```bash
npm install
npm run dev
npm run build
npm run lint
```

## Features
- Responsive section-based layout
- Selected projects linked to GitHub repositories
- About, skills and contact sections
- No third-party analytics or tracking

## Deployment
Build with `npm run build` and publish `dist` using GitHub Pages, Netlify or Vercel. Configure the Vite base path for repository-subpath deployments.
